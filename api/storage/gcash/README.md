Place the official QR image here, named `pocketfinds-qr.png`.

Use a PNG or JPG up to 5 MB. For JPG, change `qr_path` in
`api/config/gcash.php` to match the filename.

Set the registered account name, number and support email in that PHP config,
then set `enabled` to `true`. Restart the app PHP API if it is running.
